# Rescale 智能增长模板

Next.js + React + TypeScript + Framer Motion 双语响应式 AI 分析官网。包含首页、联系、期刊、六篇文章及 404。默认中文，英文位于 /en。

固定 Node 24.16.0 与 pnpm 12.10.1，执行 pnpm install --frozen-lockfile、pnpm dev，默认端口 43340；Ctrl+C 停止。

检查：pnpm typecheck、pnpm lint、pnpm test、pnpm build。生产 pnpm start。表单仅本地校验，不发送或保存。修改入口见 .tpl/customization.json。
